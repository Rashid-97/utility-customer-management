# API Contract

Base path: `/subscribers`

The API uses Pydantic schemas. Application commands and query results remain independent of HTTP models.

## Endpoints

| Method | Path | Success |
|---|---|---|
| `POST` | `/subscribers` | `201` for a new Subscriber; `200` when an existing Subscriber receives an account |
| `GET` | `/subscribers/{subscriber_id}` | `200` with the Subscriber and accounts |
| `POST` | `/subscribers/{subscriber_id}/accounts` | `201` with the new account |
| `GET` | `/subscribers/{subscriber_id}/accounts/{account_id}` | `200` with one account |
| `POST` | `/subscribers/{subscriber_id}/accounts/{account_id}/termination` | `204` with no body |

Termination is a business transition, so it uses an explicit action endpoint rather than `DELETE`.

## Requests

### Register Subscriber

```json
{
  "document_number": "AZE-ADULT-001",
  "document_type": "NATIONAL_ID",
  "service_address_id": "SERVICE-ADDRESS-001",
  "city_code": "10",
  "street_code": "20",
  "building_code": "30",
  "apartment_code": "40"
}
```

`document_type` accepts `NATIONAL_ID` or `PASSPORT`.

First name, last name, date of birth, and citizenship are not accepted from the client. They come from the verified Identity response.

### Create account

```json
{
  "service_address_id": "SERVICE-ADDRESS-002",
  "city_code": "10",
  "street_code": "20",
  "building_code": "30",
  "apartment_code": "41"
}
```

New resource UUIDs are generated by the server. Route IDs always identify existing resources.

Termination has no request body.

## Errors

All handled errors use:

```json
{
  "code": "STABLE_MACHINE_CODE",
  "message": "Safe client-facing explanation"
}
```

| Status | Code | Meaning |
|---|---|---|
| `404` | `SUBSCRIBER_NOT_FOUND` | Subscriber does not exist |
| `404` | `SUBSCRIBER_ACCOUNT_NOT_FOUND` | Account does not exist under the Subscriber |
| `409` | `ACTIVE_ACCOUNT_ALREADY_EXISTS` | An active account already uses the address |
| `409` | `SUBSCRIBER_CODE_ALREADY_EXISTS` | SubscriberCode is already used |
| `409` | `OUTSTANDING_DEBT` | Debt prevents account creation or termination |
| `409` | `SUBSCRIBER_ACCOUNT_ALREADY_TERMINATED` | Account is already terminated |
| `409` | `DATABASE_CONFLICT` | A database constraint rejected a concurrent/conflicting write |
| `422` | `IDENTITY_VERIFICATION_REJECTED` | Identity was not verified |
| `422` | `ADDRESS_VERIFICATION_REJECTED` | Address was not valid and serviceable |
| `422` | `APPLICANT_UNDERAGE` | Applicant is younger than 18 |
| `422` | `INVALID_DOMAIN_VALUE` | A domain value is invalid |
| `422` | `REQUEST_VALIDATION_ERROR` | The HTTP request shape is invalid |
| `503` | `EXTERNAL_SERVICE_UNAVAILABLE` | Identity, GIS, or Billing is unavailable |

An external outage is not reported as a business verification rejection. Raw SQL errors and internal traces are never exposed.
